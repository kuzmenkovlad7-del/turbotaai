# TurbotaAI — Чеклист внешнего QA

> Версия: 2026-05-21  
> Используйте этот чеклист для ручного тестирования на iOS и Android.

---

## 1. Регистрация и вход

- [ ] Регистрация с корректным email и паролем ≥6 символов — успешна
- [ ] Регистрация с уже существующим email — показывает ошибку
- [ ] Регистрация с паролем <6 символов — показывает ошибку
- [ ] Регистрация с несовпадающим подтверждением пароля — показывает ошибку
- [ ] После регистрации аккаунт сразу активен (email-подтверждение не требуется)
- [ ] Вход с правильными данными — успешен, открывается Home
- [ ] Вход с неверным паролем — показывает сообщение об ошибке
- [ ] Вход с несуществующим email — показывает сообщение об ошибке
- [ ] После входа доступны все разделы: Чат, Голос, Видео, Аккаунт

---

## 2. Email-подтверждение

- [ ] При регистрации email-подтверждение не требуется (аккаунт активен сразу)
- [ ] На email НЕ приходит письмо-подтверждение (ожидаемое поведение)
- [ ] Регистрация с несуществующим доменом email (@example123.xyz) проходит успешно
- [ ] Восстановление пароля отправляет письмо только если email реально существует

---

## 3. Восстановление пароля

- [ ] Нажатие "Забыл пароль" открывает форму запроса ссылки
- [ ] Ввод зарегистрированного email → показывается сообщение "письмо отправлено"
- [ ] Ввод незарегистрированного email → показывается то же сообщение (без раскрытия данных)
- [ ] Переход по ссылке из email → открывается страница turbotaai.com/reset-password
- [ ] Страница сброса пароля определяет язык автоматически
- [ ] Установка нового пароля <8 символов → показывает ошибку
- [ ] Несовпадающие пароли → показывает ошибку
- [ ] Успешный сброс пароля → показывает подтверждение
- [ ] После сброса возможен вход с новым паролем
- [ ] Повторное использование той же ссылки → показывает "ссылка истекла"

---

## 4. Чат

- [ ] Первый запуск чата → показывается окно согласия на AI (AiConsentModal)
- [ ] Без согласия запросы не отправляются
- [ ] После согласия чат работает корректно
- [ ] Сообщение отправляется по кнопке "Отправить" и по Enter
- [ ] Ответ ИИ отображается с анимацией (typewriter)
- [ ] Пока ИИ отвечает → показывается индикатор (три точки)
- [ ] Над полем ввода отображается счётчик оставшихся вопросов (в trial)
- [ ] После исчерпания 5 вопросов → поле ввода заменяется paywall-баром
- [ ] Максимальная длина сообщения — 2000 символов (кнопка не активна при превышении)
- [ ] Чат сохраняется в истории (раздел История)
- [ ] Ответы ИИ связны с предыдущими сообщениями (контекст работает)

---

## 5. Голосовой ассистент

- [ ] Выбор пола голоса (женский / мужской) работает
- [ ] При первом запуске → запрос разрешения на микрофон
- [ ] Отказ от разрешения → показывает понятное сообщение об ошибке
- [ ] Орб меняет цвет: серый (ожидание) → синий (слушает) → жёлтый (обрабатывает) → зелёный (говорит)
- [ ] Речь распознаётся корректно (кириллица + латиница)
- [ ] Тишина 4.5 секунды → автоматическая отправка запроса
- [ ] Ответ ИИ воспроизводится голосом
- [ ] Кнопка "Завершить звонок" останавливает сессию
- [ ] При ошибке (сеть) → показывается кнопка "Повторить"
- [ ] При исчерпании trial во время сессии → показывается paywall
- [ ] Триал-чип над кнопкой Start показывает количество оставшихся вопросов

---

## 6. Видеоассистент

- [ ] Выбор персонажа (Dr. Mia / Dr. Alex / Dr. Leo) работает
- [ ] Запрос разрешения на микрофон и камеру при первом запуске
- [ ] Видео-аватар отображается в формате 16:9
- [ ] В режиме ожидания → проигрывается idle-лупа
- [ ] При ответе ИИ → переключается на speaking-лупу
- [ ] После завершения ответа → возврат к idle-лупе
- [ ] Транскрипция разговора отображается в нижней части экрана
- [ ] Кнопка "Завершить звонок" работает
- [ ] Смена персонажа обновляет видео-аватар

---

## 7. Лимит пробного периода

- [ ] Новый аккаунт / новое устройство → 5 вопросов в trial
- [ ] Счётчик уменьшается на 1 после каждого ответа ИИ
- [ ] На 5-м вопросе счётчик показывает "1 вопрос остался"
- [ ] После 5 вопросов → блокировка во всех разделах (чат, голос, видео)
- [ ] Paywall показывает корректное сообщение и кнопку перехода к подписке
- [ ] При одновременном входе с другого устройства — баланс не дублируется
- [ ] Использование вопросов в чате уменьшает баланс для голоса/видео (единый счётчик)

---

## 8. Подписка (покупка)

- [ ] Экран "Аккаунт" показывает текущий статус доступа (trial / paid / promo / none)
- [ ] Кнопка покупки видна при отсутствии активной подписки
- [ ] Кнопка покупки НЕ видна при активной подписке
- [ ] iOS: нажатие "Купить" открывает стандартное диалоговое окно Apple
- [ ] Android: нажатие "Купить" открывает Google Play Billing диалог
- [ ] После успешной покупки → подписка активируется, счётчик trial скрывается
- [ ] Информация об IAP (цена, условия) отображается до покупки
- [ ] Ссылки на Privacy Policy и EULA работают
- [ ] При уже активной подписке попытка купить снова → показывает соответствующее сообщение

---

## 9. Восстановление покупки

- [ ] iOS: кнопка "Восстановить покупки" видна на экране Аккаунта
- [ ] iOS: нажатие кнопки → StoreKit restore flow
- [ ] iOS: после успешного восстановления → подписка активируется
- [ ] iOS: при отсутствии покупок для восстановления → показывает соответствующее сообщение
- [ ] Android: управление подпиской через кнопку "Управление подпиской" (Play Store)
- [ ] Подписка, купленная на iOS, не отображается на Android (разные платформы)

---

## 10. Аккаунт / профиль

- [ ] Экран показывает email пользователя
- [ ] Показывает статус доступа: paid / promo / trial (N вопросов) / заблокирован
- [ ] Показывает дату окончания подписки (если платная)
- [ ] Удаление аккаунта: показывает подтверждение, удаляет аккаунт
- [ ] После удаления аккаунта → выход, невозможность войти с теми же данными
- [ ] Промокод (Android/Web): поле ввода работает, успешный код добавляет promo-доступ
- [ ] Промокод скрыт на iOS (требование Apple Guideline 3.1.1)

---

## 11. Язык

- [ ] Приложение определяет язык устройства автоматически
- [ ] Поддерживаемые языки: украинский, русский, английский
- [ ] Смена языка в настройках → интерфейс обновляется
- [ ] ИИ отвечает на том же языке, что и вопрос
- [ ] TTS воспроизводится правильным голосом (мужской/женский) вне зависимости от языка

---

## 12. Плохая сеть

- [ ] Отправка сообщения без интернета → показывает понятное сообщение об ошибке
- [ ] В голосовом режиме при потере сети → показывается ошибка с кнопкой "Повторить"
- [ ] При восстановлении сети → приложение корректно продолжает работу
- [ ] История загружается без интернета → показывает ошибку с кнопкой "Повторить"
- [ ] WebView (если используется) при ошибке загрузки → кнопка "Повторить"

---

## 13. Перезапуск приложения

- [ ] После перезапуска → автоматический вход (токены сохранены в SecureStore)
- [ ] После перезапуска → статус доступа синхронизируется с сервером (bootstrap)
- [ ] История чатов сохраняется после перезапуска
- [ ] Сессия голос/видео не восстанавливается (новая сессия после перезапуска)
- [ ] Если токен истёк → показывается экран входа

---

## 14. Один аккаунт на нескольких устройствах

- [ ] Вход с одного аккаунта на двух устройствах — возможен одновременно
- [ ] Подписка / promo-доступ отображается на обоих устройствах
- [ ] Использование вопросов trial на одном устройстве уменьшает баланс на другом
- [ ] Покупка подписки на одном устройстве → после синхронизации активна на другом
- [ ] Выход на одном устройстве → сессия другого устройства продолжает работать

---

## 15. Различия iOS / Android

- [ ] iOS: нет поля промокода (скрыто по Apple Guideline)
- [ ] iOS: есть кнопка "Восстановить покупки"
- [ ] iOS: нет кнопки управления auto-renew (управляется через настройки Apple)
- [ ] Android: есть поле промокода
- [ ] Android: нет кнопки "Восстановить покупки" (есть "Управление подпиской")
- [ ] Android: кнопка "Завершить сессию вручную" в голосе/видео (доп. кнопка для ненадёжного VAD)
- [ ] iOS: permission диалог — один запрос, корректная локализация
- [ ] Android: permission диалог — отдельные запросы для микрофона и камеры
- [ ] Внешний вид аватаров одинаков на обеих платформах
